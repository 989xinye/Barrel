【项目名称】
Barrel - 专为 Mac 玩家打造的极简免费 Steam 容器

【一句话简介】
一个利用 AI 辅助、耗时 8 小时手搓的 Mac 运行 Windows Steam 的开源工具。

【项目简述】
极简的 Mac 运行 Windows Steam 的容器。没有花里胡哨的界面，只有最纯粹的功能。下载、解压、点开即可使用。

完全免费，绝无内购：本软件永远免费开源。就算你通过黑客手段强行把钱打进开发者的银行卡，也不会解锁任何隐藏功能。该没有的功能就是没有。

拒绝臃肿：没有开屏广告，没有弹窗推送，没有求赞助的按钮。点开即用，用完即走。
【核心功能与已知限制】

已打通 Steam 网络穿透、TLS 加密、中文字体注入以及游戏下载入库。
内置 DXMT 图形转译测试版，已成功突破底层限制，能让部分 Unity 3D 游戏（如《米塔》）成功启动。
性能预警：受限于底层转译机制，游戏性能损耗可达 20%~40%，暂不封顶。在帧数表现上客观会略逊于收费的商业软件，请抱有合理预期。
界面渲染限制：受限于 Wine 底层的 CEF 渲染死锁，Steam 界面可能存在纯黑无字的情况。此时请直接使用手机 Steam App 扫码登录，或凭感觉盲点。
